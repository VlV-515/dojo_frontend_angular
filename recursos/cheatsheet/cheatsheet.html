Reglas de oro

  • El backend valida todo. Guards y botones ocultos son experiencia de usuario, no seguridad.
  • Nada secreto en un environment: termina en el bundle y se lee con las DevTools.
  • npm ci al clonar y en CI. npm install solo para cambiar dependencias (toca el lock).
  • Node de .nvmrc (nvm use). Otra versión = "en mi máquina sí funciona".
  • Estado inmutable: arreglos y objetos nuevos, nunca push ni obj.x = ….
  • Nunca tragues errores: catchError(() => EMPTY) sin aviso deja spinners eternos.
  • Rutas siempre lazy; privadas siempre con canMatch.

DI y detección de cambios

  • @Injectable({ providedIn: 'root' }): singleton y tree-shakable.
  • InjectionToken para valores (API_URL); en tests: { provide: API_URL, useValue: '/api' }.
  • inject() solo en contexto de inyección: campos, constructor, guards, interceptores.
zone.jsRevisa tras cada evento, timer o petición. La mayoría de los proyectos existentes.
OnPushSolo si cambia un input (por referencia), un evento propio o un signal leído.
ZonelessDefault en apps nuevas de Angular 21. Signals + eventos.
"No se actualiza hasta que paso el mouse": mutación o cambio async sin signal en OnPush.

Formularios reactivos tipados

form = inject(NonNullableFormBuilder).group({
  clave:  ['', [Validators.required, claveValida]],
  nombre: ['', [Validators.required, noSoloEspacios,
                Validators.maxLength(80)]],
});
guardar() {
  if (this.form.invalid) {
    this.form.markAllAsTouched(); return;
  }
  const { clave, nombre } = this.form.getRawValue();
  // { clave: string; nombre: string }
}
  • getRawValue() incluye deshabilitados; value no.
  • required acepta " ": usa noSoloEspacios.
  • No deshabilites Guardar por invalidez; sí mientras guarda.
  • 409 del servidor junto al campo: control.setErrors({ servidor: msg }).
  • Validador = (control) => ValidationErrors | null, una regla y un nombre.

Servicio HTTP tipado

@Injectable({ providedIn: 'root' })
export class AlmacenesService {
  private http = inject(HttpClient);
  private url = `${inject(API_URL)}/almacenes`;
  listar(soloActivos = false): Observable<Almacen[]> {
    const params = soloActivos
      ? new HttpParams().set('activos', 'true')
      : undefined;
    return this.http
      .get<Respuesta<Almacen[]>>(this.url, { params })
      .pipe(map(r => r.datos ?? []));
  }
}

Devuelve Observable · desenvuelve datos · sin toasts · HttpParams, no strings concatenados.

Interceptores y política de errores

withInterceptors([carga, auth, error,
  ...(mock ? [mockInterceptor] : [])])
petición:  carga -> auth -> error -> mock/backend
respuesta: carga <- auth <- error <- mock/backend
StatusQuién lo muestra
0, 403, 5xxInterceptor (toast)
401Interceptor: cierra sesión y va a /login
400, 404, 409Componente, junto al campo o la tabla
  • req.clone({ setHeaders }): las peticiones son inmutables.
  • Token solo a tu API (req.url.startsWith(apiUrl)).
  • Opciones por petición: HttpContextToken (silencioso()), no headers inventados.
  • ErrorApp.notificado evita mostrar dos veces.

Seguridad en el front

{{ x }}Escapado: seguro

  • Token: memoria > sessionStorage > localStorage. Mejor: cookie HttpOnly.
  • Nunca token en query params, logs ni mensajes de error.
  • ?volver=: solo rutas internas (no //, /\, https:).
  • Sin source maps ni detalles técnicos del backend en producción.

Checklist antes de abrir un PR

  • npm test, npm run lint, npm run format:check, npm run build en verde.
  • Sin any, sin console.log, sin código comentado.
  • Rutas nuevas lazy y con canMatch; permiso registrado.
  • Errores: nada tragado, 4xx junto al campo, spinners que se apagan.
  • Estado inmutable; nada de suscripciones colgando.
  • Botones con nombre accesible; probado con teclado.
  • Mock actualizado si cambió el contrato.
  • Descripción: qué, por qué, cómo se probó, capturas.
